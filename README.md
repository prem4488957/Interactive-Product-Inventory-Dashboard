
# Interactive Product Inventory & Analytics Dashboard

## Project Overview
A console-based inventory management application developed using JavaScript. It demonstrates core JavaScript concepts through product management and financial analytics.

## Features
- Add products using prompt()
- Store products using arrays and objects
- Validate user inputs using if-else
- Assign Budget, Standard and Premium categories
- Search inventory using loops
- Calculate total inventory value
- Apply tax and discount calculations
- Filter affordable products
- Generate formatted inventory reports

## Technologies Used
- HTML5
- JavaScript

## JavaScript Concepts Implemented
1. Variables and Data Types
2. Arrays and Objects
3. Conditional Statements
4. Switch Statements
5. Loops, Break and Continue
6. Regular and Arrow Functions
7. Local Scope
8. forEach(), filter() and map()
9. Type Conversion

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Enter the product name and price when prompted.
4. Press F12 and open the Console tab to view the results.
